# Jogo da Velha (Tic-Tac-Toe)

Bem-vindo ao Jogo da Velha! Este é um jogo simples para dois jogadores onde você pode inserir os nomes dos participantes e alternar turnos para jogar. O jogo exibirá o vencedor quando a partida for concluída.

## Recursos

* Jogo para dois jogadores: Divirta-se com uma partida clássica de Jogo da Velha com um amigo e veja quem consegue superar o adversário para alcançar a vitória.

* Nomes de jogadores personalizáveis: Personalize o jogo inserindo nomes para o Jogador X e Jogador O, adicionando um toque pessoal às suas partidas.

* Jogabilidade interativa: O jogo oferece uma interface interativa e fácil de usar. Basta clicar nas células para realizar as jogadas. O tabuleiro destaca o turno do jogador atual para garantir uma experiência fluida.

* Anúncio de vitória: Quando um jogador vence a partida, a aplicação exibe o nome do vencedor acompanhado de uma mensagem de comemoração.

* Design responsivo: Seja no computador, tablet ou dispositivo móvel, o design responsivo garante uma excelente experiência em qualquer tela.

* Reinício rápido: Quer começar uma nova partida? Um botão de reinício permite limpar o tabuleiro rapidamente para iniciar um novo jogo.

## Tecnologias Utilizadas

* HTML

* CSS
