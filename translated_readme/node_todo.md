# Aplicação Node Todo

Uma aplicação Node desenvolvida com MongoDB e Angular. Criada para fins de demonstração e tutoriais.

O Node fornece a API RESTful, o Angular fornece a interface frontend e acessa a API, e o MongoDB armazena os dados.

## Requisitos

* [Node e npm](http://nodejs.org)

* MongoDB: Certifique-se de ter sua própria URI de banco de dados MongoDB (local ou remota) configurada em `config/database.js`

## Instalação

1. Clone o repositório: `git clone git@github.com:scotch-io/node-todo`

2. Instale as dependências da aplicação: `npm install`

3. Insira sua própria URI do MongoDB em `config/database.js`

4. Inicie o servidor: `node server.js`

5. Acesse no navegador pelo endereço `http://localhost:8080`
