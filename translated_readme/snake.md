# URL Snake

Jogue o clássico jogo da cobrinha diretamente na URL!

<https://demian.ferrei.ro/snake>

É assim que o jogo deve ser exibido:

Observe que o jogo pode ser inexecutável em alguns navegadores por diferentes motivos, como o navegador não exibir a URL completa, não permitir que ela mude com tanta frequência, ou realizar o escape dos caracteres Braille usados para renderizar o jogo.

Embora este jogo seja uma espécie de brincadeira, relatórios de bugs, ideias e pull requests são sempre [bem-vindos](https://github.com/epidemian/snake/issues)!
